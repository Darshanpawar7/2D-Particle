# 2D-Particle
Jackfruit Particle System Project (C Language)

NAMES AND SRNS: 
DARSHAN P PAWAR(PES2UG24CS143)
DEEPTHI N REDDY(PES2UG24CS149)
GANAVI PURUSHOTHAMA(PES2UG24CS167)

Files:
- particle.h     (header definitions)
- particle.c     (implementation)
- main.c         (program entry point)

To compile:
gcc main.c particle.c -o particle
gcc main_manual.c particle_manual.c -o particle

To run:
./particle

You can add more particles in main.c and modify their initial positions/velocities.
